# تطبيق د. وائل لسطح المكتب (Windows / macOS / Linux)

نفس الصفحة والتصميم بدون أي تعديل في الشكل، داخل تطبيق Electron، مع نفس مزايا تطبيق الأندرويد:
منع لقطة الشاشة، التحميل بدون إنترنت، الإشعارات والتذكيرات، تغيير الأيقونة، نوافذ التنبيه بتصميم التطبيق، والتحديث التلقائي.

## الرفع على GitHub (مرة واحدة)
1. أنشئ Repo **Public** جديد باسم `DrWael-Desktop` (لو اخترت اسمًا آخر غيّره في `package.json` ← `build.publish.repo` وفي `main.js` ورابط صفحة التحميل).
2. ارفع ملف الـ zip كما هو في الجذر، أو فُكّه وارفع محتوياته. (لو رفعت الـ zip، الـ workflow يفكه بنفسه.)
3. أضف ملف `.github/workflows/build.yml` (موجود داخل الـ zip). بعد أول push يبدأ البناء.
4. بعد دقائق تجد في Releases: `DrWael-Setup.exe` (ويندوز) و`DrWael-mac.dmg` (ماك) و`DrWael-linux.AppImage` و`.deb` (لينكس).

روابط التحميل الثابتة (تُحدَّث تلقائيًا مع كل إصدار) مستخدمة في صفحة «تحميل التطبيق» بالموقع:
`https://github.com/khaledahmed34567/DrWael-Desktop/releases/latest/download/DrWael-Setup.exe`

## التحديث التلقائي
- ويندوز ولينكس (AppImage): يفحص التطبيق آخر Release عند التشغيل، يحمّله، ويسألك بنافذة بتصميم التطبيق: «إعادة التشغيل الآن؟».
- ماك: يفتح صفحة آخر إصدار (التحديث التلقائي في ماك يحتاج شهادة توقيع Apple).
- رقم الإصدار = `1.0.N` حيث N رقم تشغيل الـ workflow.

## تسجيل الدخول بجوجل
جوجل تمنع الدخول داخل نوافذ التطبيقات المدمجة، لذلك يُفتح المتصفح الافتراضي، تسجّل منه، ثم يرجع التطبيق مسجّل الدخول تلقائيًا.
المطلوب في Firebase: Authentication ← Settings ← Authorized domains، تأكد أن `localhost` موجود (موجود افتراضيًا).

## ملاحظات
- التطبيق يعمل من العنوان `http://localhost:47831`. لو قيّدت الـ API key بالدومينات (موصى به)، أضف: `http://localhost:47831/*`.
- منع التصوير (`setContentProtection`) يعمل في ويندوز وماك، ولا أثر له في لينكس.
- ويندوز سيعرض تحذير SmartScreen لأن التطبيق غير موقّع برخصة (Code Signing). اضغط More info ← Run anyway.
- الإغلاق (X) يخفي التطبيق في الـ Tray لتبقى التذكيرات والإشعارات تعمل؛ للخروج الكامل من قائمة أيقونة الـ Tray.
- لإخفاء إعدادات المشروع من الريبو: ضع محتوى `config.json` في Secret باسم `APP_CONFIG_JSON`.

## التشغيل محليًا
```
npm install
npm start
```
